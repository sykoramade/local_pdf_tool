# Competitive Analysis

## The Problem Space
Most PDF tools online are designed to extract money, not deliver value.
Common dark patterns: fake "free" tiers, quality degradation unless you pay, forced account creation, confusing cancellation flows.

## Key Competitors to Target

### mybestpdf.com and clones
- Lock features after you've started working (bait-and-switch)
- Often process files server-side with no clear privacy policy
- Aggressive upsell popups
- SEO spammy — rank for "free pdf editor" then hit you with a wall

### ilovepdf.com
- Legitimate but ad-heavy and slow
- File size limits on free tier
- Server-side processing

### smallpdf.com
- Better UX but expensive ($9-12/mo)
- All server-side

### Adobe Acrobat online
- Expensive, heavy, requires account
- Dominates brand search but loses on "free" and "no signup" queries

## Our Positioning
**"The PDF editor that doesn't screw you."**
- 100% client-side: your files never leave your computer (verifiable, market this hard)
- No account required for core features
- Honest about what's free vs paid
- Fast: no upload/download roundtrip — processing is instant in-browser

## SEO Opportunities
Target "alternative to" and "vs" keywords:
- "mybestpdf alternative"
- "free pdf editor no upload"
- "pdf editor no account"
- "edit pdf text online free"
- "pdf editor privacy"

## Pricing Hypothesis
- Free: basic text editing, up to 5 pages
- Pro $9/mo: unlimited pages, all tools, priority support
- Target: ~170 Pro users = $1.5k MRR
